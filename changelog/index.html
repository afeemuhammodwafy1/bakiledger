What’s new?

Release history for BakiLedger.

VERSION 1.2

More control, clearer records.

  • Added Total Shops to the home dashboard.
  • Improved shop details with clearer current due and balance summaries.
  • Added phone number actions with Call and Copy.
  • Added Share Statement for a shop.
  • Added PDF statement export for a shop.
  • Added shop-wise CSV export alongside full-data CSV export.
  • Added Undo after deleting a transaction.
  • Improved transaction history labels, amounts, timestamps and optional notes.
  • Improved opening balance explanation.
  • Added JSON restore preview with Replace, Merge and Cancel choices.
  • Added clearer delete confirmations and action feedback.
  • Updated creator text to “Created by Afee Muhammod Wafy”.
  • Removed the Edit Transaction option from the app.
VERSION 1.0

Initial release

  • Multiple shop tracking
  • Due and payment transactions
  • Opening balance support
  • Transaction history with timestamps
  • Daily summary
  • JSON backup and restore
  • CSV export
  • Offline local storage
